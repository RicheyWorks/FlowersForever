# Florist availability export

FlowersForever does not host a buyer storefront. For the pilot, growers share
**live cooler stock** (and this week’s planned stems) with florists via:

1. **Inventory → Share availability…** or **File → Share availability with florists…**
2. **Copy for florists** — plain text for email, SMS, or notes
3. **Save CSV…** — columns: `Product,Quantity,Unit,Price,Week start,Week end,Planned stems,Notes`
4. **Open email draft…** — prefilled body; CSV is also copied so you can attach it

`Quantity` is **live inventory** (what can ship now). `Planned stems` is the
Production Studio / season-plan estimate for the current week — confirm before
promising. The CSV shape is intentionally simple for **Florlist-style** or
spreadsheet import; map columns in the marketplace if names differ.

Season Planner → Availability outlook still copies a **planning-only** TSV for
buyer conversations about future weeks.

For your own buying and cutting list across upcoming orders, see the
[stem demand board](STEM_DEMAND_BOARD.md).
